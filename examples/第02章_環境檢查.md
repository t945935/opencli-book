# 第 2 章實作｜建立環境檢查紀錄

## 目標
確認 Node.js、OpenCLI、CLI 說明與 Browser Bridge 診斷結果，並記下需要人工處理的環境問題。

## 步驟

```bash
node --version
opencli --version
opencli --help
opencli doctor
```

若尚未安裝，先查看 OpenCLI 官方 README 的安裝方式與 Node.js 版本要求，再由使用者決定是否進行全域安裝；以下指令會改變本機環境，不要在未確認目標版本時直接執行：

```bash
npm install -g @jackwener/opencli
```

## 紀錄表

| 項目 | 實際結果 |
|---|---|
| 作業系統 | 讀者填寫 |
| Node.js | 貼上 `node --version` |
| OpenCLI | 貼上 `opencli --version` |
| `doctor` | 原樣摘要；不得貼憑證或私人網址 |
| 未解決項目 | 例如擴充功能未連線、多個 profile 未選定 |

## 驗收
安裝成功與瀏覽器連線成功是兩個不同檢查。不要因 `opencli --version` 有輸出就宣稱 Browser Bridge 可用。

## 驗證狀態
命令名稱已和本機 OpenCLI 1.8.8 核對；安裝流程與 Node.js 要求需在出版前依官方文件再核對，未在本練習中執行安裝。
