# 第 7 章實作｜擷取公開頁面並核對來源

## 目標
對公開測試頁擷取少量文字，記下來源 URL，並區分「取得文字」與「內容已核實」。

## 使用方式
在已確認的 profile 與 session 下，以公開頁面為目標：

```bash
opencli --profile <已確認的profile別名> browser article open https://example.com
opencli --profile <已確認的profile別名> browser article state
opencli --profile <已確認的profile別名> browser article extract
```

各子命令參數可能隨版本改變，先以 `opencli browser --help` 核對。`extract` 用來取得頁面文字；若需要網路請求形狀，查看 `network` 的摘要後，只按需讀取單一項目的詳細內容，不要一開始抓全部原始資料。

## 核對步驟
- 記錄擷取時間、來源 URL、需要的欄位。
- 人工開啟同一公開頁面核對標題或一段短文字。
- 不保存 Cookie、請求授權標頭或無關個資。
- 對被截斷、載入不全或來源不一致的結果標記「未驗證」。

## 驗收
輸出摘要帶有來源連結，且文字能在原頁找到。這份範例沒有預填假造內容，也不把網路請求日誌視為可公開資料。
