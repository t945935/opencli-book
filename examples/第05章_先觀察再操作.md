# 第 5 章實作｜在公開測試頁觀察頁面狀態

## 前提
先完成第 4 章，並由使用者明確選定瀏覽器 profile。若 profile 仍有歧義，停在此處，不啟動頁面操作。

## 任務
開啟公開的 `https://example.com`，檢查 URL、標題與頁面快照；本練習只讀取，不點擊、不輸入、不提交。

## 命令形式

```bash
opencli --profile <已確認的profile別名> browser read_demo open https://example.com
opencli --profile <已確認的profile別名> browser read_demo state
```

上述 `<已確認的profile別名>` 是替換用佔位文字。命令結構以本機 `opencli browser --help` 核對；在需要登入或無法控制的環境不要繼續。

## 操作原則
1. `state` 中找到元素後才使用它的當前 ref。
2. 導航或頁面更新後重新執行 `state`；不要跨頁重用舊 ref。
3. 記錄 URL 和標題作為證據，不保存無關頁面資料。
4. 結束後可用同一 session 的 `close` 釋放工作階段；先確認不會中斷使用者正在使用的分頁。

## 驗收
URL 是預期公開測試網址，頁面標題與快照有可讀內容，且本次沒有發生寫入操作。此檔描述可執行步驟，未代表已在讀者電腦實測。
