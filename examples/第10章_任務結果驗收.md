# 第 10 章實作｜區分命令完成與資料正確

## 目標
對唯讀的 Hacker News 查詢，分別驗收程序回應、資料結構與來源內容。

## 執行

```bash
opencli hackernews top --limit 3 -f json > /tmp/opencli-top.json
python3 -c 'import json; p="/tmp/opencli-top.json"; d=json.load(open(p)); print("count:",len(d)); print("keys:",sorted(d[0]) if d else [])'
```

輸出包含動態資料，這裡不預先寫入固定文章或排名。

## 三層驗收
1. **程序**：命令是否以 exit code 0 結束；失敗時保留錯誤訊息但先遮蔽敏感資訊。
2. **結構**：JSON 可解析、筆數不超過 3、項目包含預期欄位。
3. **語意**：人工開啟至少一個 `url`，確認標題與來源相符。

> 這個 Python 快檢假設 JSON 非空；若回應為空或網站錯誤，先查原因，不要把索引錯誤誤當資料驗收通過。

## 驗收紀錄
用 `../templates/結果驗收紀錄.md` 記錄版本、命令摘要、筆數、欄位、來源抽查與未驗證事項。此任務唯讀；不可把命令 exit code 當成內容正確證明。
