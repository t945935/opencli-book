# 第 6 章實作｜用本機測試表單練習輸入與讀回

## 安全邊界
本章用本 repo 的靜態測試頁（`../fixtures/safe-form.html`）。只使用虛構資料；頁面不連接外部服務，也沒有真正提交功能。先在本機啟動 HTTP server，勿改成真實登入、付款或申請表單。

## 啟動測試頁
在 repo 根目錄執行：

```bash
python3 -m http.server 8765
```

保持此終端機執行，另開終端確認本機頁面可取得：

```bash
python3 -c 'import urllib.request; print(urllib.request.urlopen("http://127.0.0.1:8765/fixtures/safe-form.html").status)'
```

瀏覽器操作前，確認使用的 profile 已獲使用者選定；再用 `opencli ... browser form_lab open http://127.0.0.1:8765/fixtures/safe-form.html` 開啟頁面。

## 練習流程
1. 執行 `state` 讀取頁面欄位，從當前快照確認欄位 ref 或 CSS selector。
2. 用 `fill` 輸入虛構名稱，例如 `Sample Reader`。
3. 立刻以 `get value` 讀回欄位確認；值不一致就停止排查。
4. 用 `state` 確認頁面顯示「尚未提交」。不要點擊任何提交類按鈕；測試頁沒有送出按鈕。
5. 關閉本機 server（在 server 終端按 Ctrl+C）。

實際命令參數先看 `opencli browser --help`，並以新鮮頁面快照取得 ref；不要把示意 ref 照抄。

## 驗收
讀回欄位與輸入完全一致；本機頁面無網路寫入；測試完成後 server 已停止。瀏覽器橋接操作尚未在所有平台實測。
