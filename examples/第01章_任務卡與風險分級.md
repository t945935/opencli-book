# 第 1 章實作｜把一個網站需求變成安全任務卡

## 情境
你想整理 Hacker News 公開熱門文章的標題與來源連結。先不要操作網站介面，也不登入帳號；本練習先寫清楚目標和限制。

## 任務卡
- 目標：讀取公開熱門文章，整理前 3 筆的排名、標題與連結。
- 範圍：OpenCLI 的 `hackernews top` 唯讀 adapter；最多 3 筆。
- 禁止：登入、留言、投票、收藏、發文、發送訊息。
- 停止條件：命令需要登入、出現非預期寫入提示、輸出缺少標題或 URL。
- 驗收：輸出恰有 3 筆；每筆有 rank、title、url；人工開啟來源連結核對至少一筆。

## 先盤點本機

```bash
opencli --version
opencli list
opencli hackernews --help
```

## 完成檢查
記錄版本和當日輸出欄位。若命令清單或參數與範例不同，以本機 `--help` 為準；不要自行猜測替代命令。

## 驗證狀態
任務規格已完成。資料擷取命令屬第 3 章實作；不要將規格範例誤認為執行結果。
