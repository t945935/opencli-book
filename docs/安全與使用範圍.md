# 安全與使用範圍

## 這份配套資料的用途

本資料夾協助你規劃和檢查 OpenCLI 網站任務，不會替你安裝軟體、提供帳號憑證或保證特定網站功能持續可用。OpenCLI 和網站都會更新；請以你實際安裝版本的命令說明和官方文件為準。

## 執行前的三個檢查

1. **對象**：確認是哪個網站、哪個瀏覽器 profile、哪一個頁面和帳號。
2. **範圍**：明確列出允許讀取的資料、允許的動作、禁止的動作及停止條件。
3. **證據**：預先寫好要讀回什麼內容才能證明任務完成；不可只用「命令沒有錯誤」當驗收。

## 風險分級

- **低風險唯讀**：讀取公開頁面、擷取公開文章標題、整理公開資訊。仍需核對來源與資料內容。
- **需要確認**：登入後讀取私人資料、填入尚未送出的表單、建立草稿或更改個人偏好。先確認帳號、資料範圍與是否會保存。
- **高風險／需明確授權**：送出表單、發布內容、發送訊息、提交訂單、付款、刪除或修改他人可見資料。未取得針對該動作的明確授權時停止；執行後讀回目標狀態。

## 憑證與個資

- 不把密碼、Cookie、Session、API token、一次性驗證碼或付款資料交給模型或貼在終端命令中。
- 不提交真實個資作為測試資料；用虛構資料或公開內容。
- 分享錯誤紀錄前，檢查網址 query string、截圖、頁面文字與日誌是否含敏感資訊。

## 網站規則

遵守目標網站服務條款、資料授權、隱私規定和速率限制。不可用本教材規避付費牆、存取控制、CAPTCHA、反濫用措施或帳戶限制。若網站禁止自動化或資料再利用，停止該流程並改用官方提供的匯出/API。

## 結果驗證

至少記錄：使用的工具版本、實際目標、執行前狀態、執行結果、執行後讀回的狀態，以及任何未驗證項目。保存必要的最小證據，不收集無關個人資料。
